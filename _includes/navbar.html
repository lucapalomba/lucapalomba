{%- comment -%} Shell navbar, restyled to the Obsidian Precision spec (R05). Three groups inside a 1200px track: brand + availability badge, the numbered nav, and the actions (Curriculum CTA + language switch + hamburger). All labels come from the locale dictionary, and the current page is marked from `page.i18n_key` so one navbar serves both languages. Two controls the design has no place for, kept on purpose: - the language switcher (`.lang-toggle.lang-switch`), a glyph link to `page.alt_url` in BOTH the desktop row and the mobile drawer, because js/langPref.js listens for `.lang-switch` clicks and `hreflang` drives the alternates; - the hamburger, because the motion export has no mobile navigation at all (D8), so the existing drawer is the only working mobile affordance. The typewriter sound toggle is gone (D6), which retired js/soundMute.js and sounds/. {%- endcomment -%}
