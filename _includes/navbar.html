{%- comment -%} Shell navbar, restyled to the Obsidian Precision spec (R05). All labels come from the locale dictionary (`t`, assigned by the layout), and the current page is marked from `page.i18n_key` instead of comparing `page.url` — which is what lets one navbar serve both /en and /it pages. Links stay relative ("experiences.html") so they resolve inside whichever language directory the page lives in. Two controls the design has no place for, kept here on purpose: - the language switcher (`.lang-toggle.lang-switch`), a glyph link to `page.alt_url` in BOTH the desktop row and the mobile drawer, because js/langPref.js listens for `.lang-switch` clicks and the `hreflang` attribute drives the alternates; - the hamburger, because the motion export has no mobile navigation at all (D8), so the existing drawer is the only working mobile affordance. The sound toggle is gone: the typewriter audio was removed per D6, which retired js/soundMute.js and sounds/. {%- endcomment -%}
